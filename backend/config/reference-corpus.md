# Reference corpus for mean ablation

Mean ablation replaces a component's output with its average output over every token of these passages. They were written for this tool in mixed registers (news, instructions, narrative, description, conversation, exposition) and avoid any one rhetorical pattern. The corpus is short. A sample of OpenWebText, the corpus GPT-2 was trained on, would be the usual choice in interpretability work. Changing this file changes every mean-ablation result; recipes record its SHA-256.
